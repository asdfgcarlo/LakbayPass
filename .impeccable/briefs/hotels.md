# Destination hotel recommendations

Mode: Operate. Ordinary extension of the six destination detail pages. Preserve
all destination stories, supplied hero photos, points, missions and scanner.

## Direction contract

THESIS: give a traveler one carefully verified place to stay in the attraction's
area, with factual property details and a direct link to the hotel.

OWN-WORLD: inherit warm off-white, white surfaces, charcoal system typography,
quiet borders, 12px cards, 10px actions, and visible focus. No token changes.

STORY: below the main destination information, Where to Stay pairs an actual
property photograph with its town, two-sentence description and View Hotel link.
Island stays remain on the main island near the departure municipality.

FIRST VIEWPORT: retain the incumbent photo/story overview. The following section
uses the exact requested heading and subtitle, then a responsive card grid. A
single recommendation uses a photo/text split on desktop and stacks on phones;
multiple recommendations use independent cards in the same visual grammar.

FORM: code-led extension; no concept roll or new visual identity. Photo credits
link to the original work and its reuse license. Image failure reveals an honest
text fallback while location, description and the official link remain usable.
seed: none (ordinary extension)

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

The user approved labeled photo fallbacks wherever explicit reuse permission is
unclear. This applies to Fantasy Lodge Cebu, Mariden Resort and Camiguin Blue
Lagoon Cottages. No copyrighted official-site photos are copied for those cards.
Hue, Hotel Luna and Coco Grove use verified CC-licensed property photographs.
Never replace a property photo with unrelated scenery or add invented travel
times, prices, review scores or amenities. Verify source details as of2026-11-26.

Verify all six routes at desktop and phone widths, keyboard/native links, image
failure and no-JavaScript states, long content, and preservation of scanner entry
points. Keep the curated catalog and photo provenance available in the project.
