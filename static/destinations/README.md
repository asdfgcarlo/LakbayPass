# Destination photos

These six photos appear in the gallery and on their destination pages. Replace a file using the same filename to update both views. A missing photo uses a clearly labeled gallery placeholder:

| Filename | Destination | Attraction |
| --- | --- | --- |
| `palawan-mitras-ranch.jpg` | Palawan | Mitra’s Ranch |
| `vigan-calle-crisologo.jpg` | Vigan | Calle Crisologo |
| `cebu-binalayan-hidden-falls.jpg` | Cebu | Binalayan Hidden Falls |
| `siquijor-paliton-beach.jpg` | Siquijor | Paliton Beach |
| `siargao-sugba-lagoon.jpg` | Siargao | Sugba Lagoon |
| `camiguin-mantigue-island.jpg` | Camiguin | Mantigue Island |

Landscape photos around 1200 × 850 pixels work well. Keep `photo-placeholder.svg` as the missing-image fallback. To use a different filename or format, update the destination manifest in `app.py`.
